# @papchat/share-link

Button that hands over an invite link: the share sheet on phones, the clipboard elsewhere.

## API

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `link` | `string` | `""` | The link to share. |
| `compact` | `boolean` | `false` | Short "Invite" label on a clear button, for the header. |

No events: the button does the sharing itself and says "Copied".
